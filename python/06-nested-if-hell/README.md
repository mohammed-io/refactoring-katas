# Kata 06: Nested If Hell

## Business Scenario

This kata is about a package delivery validator. The implementation works and the tests describe the current behavior, but the code is intentionally awkward so it can be improved through refactoring.

## Component Usage

The component checks package constraints such as weight, hazards, weekend delivery, temperature, and remote areas. Treat the tests as the contract while you improve the internal design.

## How to Run

```bash
make test
```
