# Kata 16: Shotgun Surgery

## Business Scenario

This kata is about a loyalty tier billing rules. The implementation works and the tests describe the current behavior, but the code is intentionally awkward so it can be improved through refactoring.

## Component Usage

The component returns tier discounts, labels, thresholds, colors, and discounted totals. Treat the tests as the contract while you improve the internal design.

## How to Run

```bash
make test
```
