# Kata 04: Cryptic Calculator

## Business Scenario

This kata is about a survey score normalizer. The implementation works and the tests describe the current behavior, but the code is intentionally awkward so it can be improved through refactoring.

## Component Usage

The component maps raw scores into a requested target range. Treat the tests as the contract while you improve the internal design.

## How to Run

```bash
make test
```
