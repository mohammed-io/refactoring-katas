# Kata 09: Stringly Typed

## Business Scenario

This kata is about a issue tracker command handler. The implementation works and the tests describe the current behavior, but the code is intentionally awkward so it can be improved through refactoring.

## Component Usage

The component updates issue status and priority from compact command strings. Treat the tests as the contract while you improve the internal design.

## How to Run

```bash
make test
```
