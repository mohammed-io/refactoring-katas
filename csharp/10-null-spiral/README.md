# Kata 10: The Null Spiral

## Business Scenario

This kata is about a university room lookup. The implementation works and the tests describe the current behavior, but the code is intentionally awkward so it can be improved through refactoring.

## Component Usage

The component walks student, enrollment, course, section, and room lookups. Treat the tests as the contract while you improve the internal design.

## How to Run

```bash
make test
```
