# Kata 12: God Object

## Business Scenario

This kata is about a subscription account model. The implementation works and the tests describe the current behavior, but the code is intentionally awkward so it can be improved through refactoring.

## Component Usage

The component handles login, profile, billing, preferences, audit, export, and subscription changes. Treat the tests as the contract while you improve the internal design.

## How to Run

```bash
make test
```
