# Kata 20: The Legacy Monolith

## Business Scenario

This kata is about a e-commerce order monolith. The implementation works and the tests describe the current behavior, but the code is intentionally awkward so it can be improved through refactoring.

## Component Usage

The component validates, prices, discounts, taxes, pays, ships, emails, logs, and calculates loyalty points in one place. Treat the tests as the contract while you improve the internal design.

## How to Run

```bash
make test
```
