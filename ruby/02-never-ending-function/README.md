# Kata 02: The Never-Ending Function

## Business Scenario

This kata is about a online bookstore order processor. The implementation works and the tests describe the current behavior, but the code is intentionally awkward so it can be improved through refactoring.

## Component Usage

The component validates an order, checks inventory, computes totals, simulates payment, creates a shipping label, and prepares an email. Treat the tests as the contract while you improve the internal design.

## How to Run

```bash
make test
```
