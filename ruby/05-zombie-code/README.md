# Kata 05: The Zombie Code

## Business Scenario

This kata is about a marketing campaign sender. The implementation works and the tests describe the current behavior, but the code is intentionally awkward so it can be improved through refactoring.

## Component Usage

The component counts sent and skipped customers for a campaign and returns message metadata. Treat the tests as the contract while you improve the internal design.

## How to Run

```bash
make test
```
