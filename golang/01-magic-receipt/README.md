# Kata 01: Magic Receipt

## Business Scenario

This kata is about a coffee shop receipt total calculator. The implementation works and the tests describe the current behavior, but the code is intentionally awkward so it can be improved through refactoring.

## Component Usage

The component calculates item totals, customer discounts, tax, and final bill totals. Treat the tests as the contract while you improve the internal design.

## How to Run

```bash
make test
```
