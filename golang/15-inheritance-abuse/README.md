# Kata 15: Inheritance Abuse

## Business Scenario

This kata is about a employee bonus calculator. The implementation works and the tests describe the current behavior, but the code is intentionally awkward so it can be improved through refactoring.

## Component Usage

The component computes bonuses through a deep role hierarchy. Treat the tests as the contract while you improve the internal design.

## How to Run

```bash
make test
```
