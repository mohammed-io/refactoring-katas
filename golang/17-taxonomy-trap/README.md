# Kata 17: The Taxonomy Trap

## Business Scenario

This kata is about a vehicle rental pricing model. The implementation works and the tests describe the current behavior, but the code is intentionally awkward so it can be improved through refactoring.

## Component Usage

The component computes daily rental rates and fuel costs through parallel vehicle hierarchies. Treat the tests as the contract while you improve the internal design.

## How to Run

```bash
make test
```
