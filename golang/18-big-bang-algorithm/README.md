# Kata 18: Big Bang Algorithm

## Business Scenario

This kata is about a fraud risk detector. The implementation works and the tests describe the current behavior, but the code is intentionally awkward so it can be improved through refactoring.

## Component Usage

The component scores transactions based on amount, velocity, merchant, location, and timing. Treat the tests as the contract while you improve the internal design.

## How to Run

```bash
make test
```
