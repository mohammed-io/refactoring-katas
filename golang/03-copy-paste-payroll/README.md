# Kata 03: Copy-Paste Payroll

## Business Scenario

This kata is about a company payroll generator. The implementation works and the tests describe the current behavior, but the code is intentionally awkward so it can be improved through refactoring.

## Component Usage

The component creates payslips for full-time, part-time, and contract workers. Treat the tests as the contract while you improve the internal design.

## How to Run

```bash
make test
```
