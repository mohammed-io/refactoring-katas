# Kata 08: Jealous Function

## Business Scenario

This kata is about a restaurant kitchen ticket printer. The implementation works and the tests describe the current behavior, but the code is intentionally awkward so it can be improved through refactoring.

## Component Usage

The component formats an order into a kitchen ticket string. Treat the tests as the contract while you improve the internal design.

## How to Run

```bash
make test
```
